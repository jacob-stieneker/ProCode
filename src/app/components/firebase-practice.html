Command reference

Local simulator only. No accounts, real files, network requests, or cloud deployments. Each Run or Finish starts from the exercise fixture shown in State. Aliases: dev, staging, prod. 

firebase login
firebase projects:list
firebase use PROJECT_OR_ALIAS
firebase init hosting
firebase init firestore
firebase init emulators
firebase deploy --only SCOPE --project PROJECT
firebase hosting:channel:deploy CHANNEL --expires 7d --project PROJECT
firebase target:apply hosting app SITE --project PROJECT
firebase emulators:start --only auth,firestore --project demo-procode
firebase emulators:exec --only firestore --project demo-procode "npm run test:rules"

Emulator flags: --import ./seed, --export-on-exit ./saved. Fixture paths: seed, saved, export. The only available test script is npm run test:rules. Its result is simulated.

One command per line. Comments start with #. Quoted values, --flag=value, --flag value, and -P for --project are accepted. Unlisted commands, options, and shell syntax are unsupported.

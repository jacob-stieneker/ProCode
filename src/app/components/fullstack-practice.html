Runtime reference

Each scenario and each preview starts with fresh API data. Reload inside your project refetches the same session. Run checks three scenarios; Finish checks all scenarios. Edits are saved locally.

Supplied: Angular startup, template compilation, forms imports, dependency injection, a local API service, and API route dispatch. Complete the bindings, handlers, validation and data operations. index.html is the Angular template; app.ts exports AppComponent.

Client imports: @angular/core, @angular/common, @angular/forms, @angular/core/rxjs-interop, rxjs, rxjs/operators, and @procode/fullstack (PracticeApi and projectTemplate). API imports: @procode/server (createRouter). Templates support Angular bindings, control flow and forms. Use signals for state updated after asynchronous requests. External resources are blocked. Existing mount(api) clients remain supported with sanitized plain HTML.

API code runs in a separate worker. This is a local request transport and in-memory data, not a real HTTP server or Firebase backend. TypeScript is transpiled with syntax diagnostics; a full project type checker and arbitrary package imports are not provided.
